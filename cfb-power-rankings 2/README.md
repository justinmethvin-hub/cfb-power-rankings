# College Football Power Rankings (Streamlit + Odds + Email)

Deploy-ready Streamlit app with:
- Power rankings from stats (YPP/PPP, turnovers, etc.)
- Odds overlays (TheOddsAPI) + model spreads
- Confidence scoring with emoji tiers
- Post-game accuracy report
- Bankroll tracking with true odds payouts
- Monday email summary via Gmail (and optional GitHub Actions)

See `.streamlit/secrets.toml` for required secrets.
